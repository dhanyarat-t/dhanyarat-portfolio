# Dhanyarat Portfolio

Single-page personal portfolio built with HTML and Tailwind CSS (CDN).

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## Customize

- Update name, bio, projects, and contact links in `index.html`
- Tailwind utility classes can be changed directly in the markup

## Stack

- HTML
- [Tailwind CSS](https://tailwindcss.com/) via CDN
